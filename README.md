# Soundcore Multi-Vendor E-Commerce Platform

## Project Concept
An advanced multi-vendor e-commerce web platform specialized in "Soundcore" audio products. The system acts as an intermediary bridge connecting multiple primary stakeholders:
* **Customers:** Browse products, manage carts, and complete secure checkouts.
* **Sellers:** Dedicated dashboards to manage product listings, inventory, and track earnings.
* **Admin (Platform Owner):** System-wide management, vendor approvals, and commission tracking.
* **Tech Support:** Handling customer and seller tickets with escalation workflows.

---

## Tech Stack
* **Frontend:** React, JavaScript, HTML5, CSS3
* **Version Control:** Git, GitHub

---

## Current Progress
* **Environment Setup:** Initialized the project structure separating the `frontend` and configuring local development.
* **Frontend Architecture:** Built the initial SPA (Single Page Application) using React.
* **Product Catalog & UI:** Implemented a dynamic product grid displaying Soundcore items (such as C30i, Q40i, and P30i) using mock data structures mapped to simulated sellers, categories, local product images, and unified brand color styling (`#00b0ff`).
* **Shopping Cart System:** Developed interactive cart functionality supporting item quantity increments/decrements, item removal, and dynamic total price calculation.
* **Version Control:** Configured local Git tracking and established a clean GitHub repository workflow for continuous development, including repository synchronization of all UI components and assets.
