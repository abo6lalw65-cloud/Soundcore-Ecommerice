# Soundcore Multi-Vendor E-Commerce Platform

## Project Concept
An advanced multi-vendor e-commerce web platform specialized in "Soundcore" audio products. The platform connects customers with various sellers in a unified, branded environment.

## Tech Stack
* **Frontend:** React, JavaScript, HTML5, CSS3
* **State Management:** React Hooks (`useState`)
* **Version Control:** Git, GitHub

---

## Current Progress

### 1. Storefront & Cart System (Customer View)
* Built a dynamic product catalog displaying Soundcore items with local image integration.
* Developed an interactive shopping cart supporting quantity adjustments (increment/decrement) and item removal.
* Implemented real-time total price calculation.
* Applied consistent brand styling using the primary Soundcore blue (`#00b0ff`).

### 2. Seller Dashboard (Vendor View)
* Created a dedicated inventory management interface for sellers.
* Implemented a dynamic form allowing sellers to add new products with details (Name, Price, Category, Stock Quantity, Image Path).
* Added functionality to delete existing products from the seller's inventory list.
* Managed form inputs and inventory lists using React state.
